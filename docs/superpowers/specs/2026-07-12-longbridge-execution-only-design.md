# 长桥仅导入成交记录设计

## 目标

交易日志中的长桥同步只读取和导入成交记录，不读取、展示或使用账户持仓。用户可在交易日志区域输入起止日期；默认范围为最近一年至当前时间。

## 数据流

1. 用户在交易日志区域设置开始和结束日期，点击“获取长桥交易日志”。
2. 前端以 RFC3339 日期范围调用现有同步接口。
3. Go 校验范围并传给本地 sidecar；sidecar 只调用长桥的历史成交、当日成交和订单详情接口。
4. sidecar 合并并按 `trade_id` 去重，补齐成交方向、标的名称与货币，返回成交列表且 `positions` 恒为空。
5. 前端只显示成交预览；用户确认后导入交易日志。不会产生或保存任何持仓数据。

## 接口与边界

- 保持 `POST /api/v1/brokers/:id/sync` 的响应兼容性，`positions` 返回空数组，避免影响其他券商调用方。
- `start_at` 和 `end_at` 继续使用 RFC3339；无输入时为最近一年至当前时间。范围必须为正且不超过 366 天。
- 长桥历史成交接口不含当天成交，因此仍读取单独的当日成交接口；订单详情只用于补齐 Vibe 交易日志所需字段。
- 所有长桥请求均为只读；用户确认导入前不写入交易日志。

## 前端

- 在“获取券商交易日志”卡片中增加开始、结束日期输入控件。
- 日期变化时仅保存本地界面状态；点击获取时才发请求。
- 预览与提示只显示“成交”数量，不显示持仓数量。
- 当开始日期晚于结束日期时在本地阻止请求并说明错误；服务端仍执行完整校验。

## 错误处理

- 长桥 HTTP 或业务码错误保持为明确的同步错误，不伪装成空成交。
- 日期格式或范围不合法返回可读错误。
- 没有成交是正常的空预览，确认导入按钮保持不可用。

## 验证

1. Sidecar 测试断言长桥同步不请求 `/v1/asset/stock`。
2. 测试历史成交、当日成交合并、订单详情补齐和 Vibe 记录校验。
3. Go handler 测试日期范围转发与边界错误。
4. 前端测试日期输入、仅成交文案、请求参数和空预览。
5. 回归 Sidecar、Go、前端测试与生产构建。

## 非目标

- 不同步或展示持仓；
- 不自动下单；
- 不扩大长桥授权范围。
