# CANSLIM iOS 功能与设计基线

`CANSLIM-IOS` 是 Web 工作台的原生 SwiftUI 客户端。业务能力、数据含义和
REST/SSE 合约与 Web 保持一致；信息架构、导航和交互按 iPhone 使用场景重新设计。

## 功能对照

| Web 工作区 | iOS 入口 | 必须覆盖的能力 |
| --- | --- | --- |
| 选股 | `TabView / 选股` | 美股/A 股市场、扫描结果、阈值、标签过滤、预设、刷新任务、扫描 SSE、进入个股分析 |
| 分析 | `TabView / 分析` | 多股票历史、概览、公司资料、K 线、RS、EPS、营收、毛利率、二层数据、N 标签、AI 配置与 SSE、暂停/续传、Markdown 分享、创建交易计划 |
| 交易计划 | `TabView / 计划` | 状态/代码过滤、新建、编辑、执行并生成日志 |
| 交易日志 | `TabView / 日志` | 列表、录入、编辑复盘、删除、行为复盘、导出、券商成交预览与导入 |
| 设置 | `TabView / 设置` | API 地址与访问令牌、全局市场、AI 供应商/模型/分析师/辩论参数、LLM 密钥状态与管理、券商连接/同步/断开 |

## 移动端原则

- 高频区域使用稳定的五栏 Tab；详情使用 `NavigationStack`，不复刻桌面侧栏。
- 44pt 以上触控目标，按下即反馈；数据加载、成功、警告和错误均显示真实状态。
- 筛选、编辑和次要操作使用可下拉 Sheet；破坏性操作使用系统确认框。
- 图表支持横向空间压缩和 Dynamic Type；来源与数据日期不因移动端空间有限而省略。
- 动效只用于空间关系和状态反馈，默认无弹跳；遵守“减弱动态效果”。
- API 令牌仅写入 Keychain；客户端不保存或回显服务端 LLM/Broker 密钥。

## 验收基线

- 小屏、标准尺寸与 Max 尺寸模拟器无横向溢出，动态字体不遮挡关键操作。
- REST 错误显示后端原始可行动信息；SSE 只在收到 `done` 后标记完成。
- 与 Web 功能表逐项走查；成功构建后再进行模拟器和真机触控验证。

## 当前验证记录

- Xcode 26.6 / iOS 26.5 Simulator：Debug 模拟器构建通过。
- iPhone 17：已连接本地真实 API，逐页验证选股、个股概览、图表、AI 配置、计划、日志和设置。
- iPhone 17e：已验证小屏选股布局、深色模式；`extra-extra-large` Dynamic Type 下设置页关键操作无横向溢出。
- AI 截图只验证配置读取与入口状态，未触发可能产生外部模型费用的完整分析。
- 真机签名、局域网 API 地址和实际券商/LLM 凭据仍需在目标设备环境验收。
