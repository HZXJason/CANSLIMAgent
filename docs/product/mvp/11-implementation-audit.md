# AlphaLens MVP Top 5 实现审计

日期：2026-08-04

## 审计结论

Top 5 已形成一条可运行的产品主链：候选快照 → 研究证据 → 用户观点 → 交易计划 → 入场前风险审查 → 成交 → 计划执行复盘 → 有门槛的行为观察。新增“今日”作为默认入口，发现页开始使用可保存、可解释的结构化模板。

该结论不代表实时日内扫描、节假日交易日历或自然语言规则构建器已经完成。当前实现会显式展示这些边界，不用虚构数据补位。

## 功能审计

| 能力 | 已验证行为 | 仍保留的边界 |
|---|---|---|
| F1 可追溯决策主链 | 候选与研究快照不可变；用户观点版本化；计划引用观点；成交可回到原计划 | 历史快照与当前行情的并排变化提示仍可继续增强 |
| F2 AI 入场前风险审查 | 确定性冲突不依赖 AI；审查版本追加；高风险需显式确认；AI 不可用不生成替代报告 | 本次未使用真实付费 provider 做端到端审查；新闻、情绪等不可用来源保持未知 |
| F3 计划—执行复盘 | 券商成交默认计划外；必须显式关联；过程与结果分离；少于 10 个完整样本不形成稳定行为结论 | 退出、止损和持有期只有在存在真实数据时比较 |
| F4 时段化今日首页 | 默认路由为 `/today`；US/CN 时区与数据隔离；时段改变排序但不隐藏待办；空态不生成候选 | 尚未接入权威节假日日历，界面明确标记“交易日历未验证” |
| F5 统一发现引擎 | CANSLIM 成为系统模板；模板可另存和复用；规则可见；流动性数据缺失时每个候选显示未知 | 自然语言构建器与专业实时盘前数据延后；当前不宣称专业日内扫描延迟 |

## 真实运行验证

- `/api/v1/today?market=US` 返回真实待复盘成交、市场时区、会话与数据日期；
- `/api/v1/screen-definitions?asset_market=US` 返回系统 CANSLIM 模板和可见条件；
- 390px 浏览器宽度下，“今日”和“发现”无横向溢出；
- 今日页真实空态明确给出“去发现”和“记录成交”，没有虚构机会；
- 发现页加入平均成交额条件后，缓存中的每个候选均显示“平均成交额 ?”；
- 真实 MU 成交页显示“开始复盘”，在 0 个完整关联样本下只展示样本不足，不再要求用户评价一个尚未形成的行为结论。

## 上线前外部依赖
